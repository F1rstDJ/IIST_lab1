# 🚗 База знаний: Выбор автомобиля

Система поддержки принятия решений для подбора автомобиля по бюджету, условиям эксплуатации и личным предпочтениям пользователя.

Проект разработан в рамках дисциплины «Интеллектуальные информационные системы и технологии» (СГТУ им. Гагарина Ю.А., 2026).

## 📋 Описание

Проект представляет собой формализованную базу знаний экспертной системы, которая:
- Классифицирует автомобили по 10 признакам
- Хранит характеристики 8 конкретных комплектаций (LADA, HAVAL)
- Учитывает 12 объективных и 20 субъективных критериев выбора
- Содержит 16 общих и 24 индивидуальных продукционных правила
- Прошла тестирование на 18 сценариях (включая граничные случаи)

## 🎯 Ключевые особенности

- **Двухуровневая фильтрация**: сначала применяются жёсткие ограничения (бюджет, число мест, КПП, привод), затем — субъективные предпочтения
- **Объяснимость результата**: каждая рекомендация содержит номер правила, по которому она была сделана
- **Обработка отказов**: система различает три ситуации — нет допустимых авто, есть авто без совпадения предпочтений, недостаточно данных
- **Актуальные данные**: цены и комплектации взяты с официальных сайтов дилеров (сентябрь 2026)

## 📊 Структура базы знаний

### Объекты (8 комплектаций)
| Код | Модель | Цена, тыс. руб. |
|-----|--------|-----------------|
| A1 | LADA Granta Standard Plus | 850 |
| A2 | LADA Vesta Комфорт | 1601 |

| A7 | HAVAL DARGO Оптимум 4WD | 3499 |
| A8 | HAVAL H9 Премиум | 4799 |

### Критерии выбора
- **Объективные (12)**: бюджет, резерв, число мест, КПП, привод, условия движения, мощность, третий ряд, тип двигателя, режим багажа, доп. условия, полнота данных
- **Субъективные (20)**: предпочтения по кузову, марке, двигателю, КПП, комфорту и оснащению

### Продукционные правила
- **Общие (G01–G16)**: универсальны для любого пользователя (проверка бюджета, исключение неподходящих объектов, обработка конфликтов)
- **Индивидуальные (I01–I24)**: персональные предпочтения в формате «ЕСЛИ условия, ТО рекомендация»

## 💡 Пример работы

**Сценарий**: Бюджет 2 800 000 ₽, резерв 100 000 ₽, полный привод обязателен, предпочтения — кроссовер и 4WD.

**Логика системы**:
1. Доступная сумма: 2 800 − 100 = 2 700 тыс. ₽
2. По цене проходят A1–A6
3. По приводу остаются A4 (Niva Travel) и A6 (JOLION)
4. По предпочтениям срабатывает правило I16 для A6

**Результат**: HAVAL JOLION Оптимум 4WD за 2 649 тыс. ₽

## 🧪 Тестирование

Проведено 18 тестовых сценариев, включая:
- Типовые случаи подбора
- Граничные значения бюджета
- Несовместимые требования
- Недостаточные данные
- Выход за пределы каталога (электромобили, дизели)

Все сценарии дали ожидаемый результат, система не рекомендует автомобили сверх бюджета и не подменяет обязательные параметры.
